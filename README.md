One patch note (136 characters, limit 160) for a bug in real life, in the terse register of a real release note. Top five split the $5 pot equally.

## Why this line

Real release-note voice (version, 'fixed a bug'), a universally true bug (3 a.m. replay of an embarrassing moment), and the reversal in the last sentence: the fix ships a button that does nothing. The joke is the changelog itself.
